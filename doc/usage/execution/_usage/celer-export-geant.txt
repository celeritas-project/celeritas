Export Geant4 data to ROOT or JSON 


./celer-export-geant [OPTIONS] gdml [options] output


POSITIONALS:
  gdml TEXT REQUIRED          Input GDML file 
  options TEXT:((FILE) OR (Special value '-' for stdin/stdout)) OR (Empty string)
                              Options JSON file 
  output TEXT REQUIRED        Output file (ROOT or JSON) 

OPTIONS:
  -h,     --help              Print this help message and exit 
  -v,     --version           Display program version information and exit 
          --gen-test          Generate test data 
          --dump-default      Dump default options
